
# Python Odd or Even Checker

## About
This is a simple Python project that checks whether a number is odd or even.

## What it does
- Asks the user to enter a number.
- Checks whether the number is odd or even.
- Displays the result.
- Handles invalid input, such as letters, using `try` and `except`.

## What I learned
- Using `input()` to get user input.
- Converting input to integers using `int()`.
- Using the modulo operator (`%`) to check remainders.
- Using `if` and `else` statements.
- Handling errors with `try` and `except`.
